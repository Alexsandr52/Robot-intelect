# Проект Unitree G1

Источник плана и критериев готовности: [Linear: Unitree G1 — подъём коробки и система манипуляции](https://linear.app/aelxsandr/project/unitree-g1-poduyom-korobki-i-sistema-manipulyacii-886951495be0/issues) (`P-AEL-8`). Первой выполняется [AEL-73 — проверить конфигурацию G1 и текущее состояние проекта](https://linear.app/aelxsandr/issue/AEL-73/proverit-konfiguraciyu-g1-i-tekushee-sostoyanie-proekta). Актуальные статусы и зависимости задач смотреть в Linear.

## Ближайшая цель

В симуляции G1 должен захватить коробку с пола, поднять на заданную высоту и удержать, сохранив равновесие. Для результата фиксировать долю успеха, условия испытаний и причины неудач. Затем проверить перенос на реального робота и расширить систему на другие задачи манипуляции.

## План из Linear

1. Проверить конфигурацию G1, окружение, сцену, метрики и правила использования общей GPU.
2. Собрать задачу подъёма, эталонную траекторию, политику слежения и проверку в симуляции.
3. Согласовать контракт инференса и выполнить проверку на реальном G1.
4. Добавить описание контактов, проверку выполнимости и автоматический поиск.

Технологии, указанные в Linear: Python, uv, Isaac Sim / Isaac Lab, Isaac Lab-Arena и LeRobot. Совместимость чекпойнтов Isaac Lab с LeRobot требуется проверять отдельно.

## Репозиторий и данные

Корневой Git хранит собственный код и документацию. Содержимое `IsaacLab/` и `isaac_sc/` исключено: первая папка — самостоятельный клон upstream, вторая — локальные материалы сцены. Git LFS применяется к весам, USD и другим крупным бинарным форматам, размещённым **в отслеживаемых папках**, по `.gitattributes`. Генерируемые результаты в `checkpoints/`, `runs/` и `outputs/` не коммитятся автоматически. Нужный для воспроизведения вес следует отдельно скопировать в отслеживаемую папку, например `models/`, добавить в Git и описать его происхождение, команду обучения, конфигурацию, версии и метрики.

GPU общая. Чужие процессы на видеокарте нельзя останавливать без чёткого разрешения.
