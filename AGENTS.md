# Правила проекта robot-move

## Работа в репозитории

- Основной язык новой логики, скриптов и инструментов — Python. Предпочитать явные интерфейсы, управляемые параметры и воспроизводимые команды; выбор другого языка обосновывать задачей.
- Вести историю изменений в Git. Делать небольшие осмысленные коммиты; перед коммитом проверять состав добавленных файлов.
- Хранить веса моделей и крупные бинарные артефакты в Git LFS согласно `.gitattributes`. Сгенерированные временные данные, кэши и результаты запусков не добавлять в Git по умолчанию.
- Поддерживать документацию в `docs/`: записывать настройку среды, команды запуска, параметры экспериментов и результаты проверок при их появлении.
- Задачи и порядок работ брать из проекта Linear [Unitree G1 — подъём коробки и система манипуляции](https://linear.app/aelxsandr/project/unitree-g1-poduyom-korobki-i-sistema-manipulyacii-886951495be0/issues). При работе над задачей ссылаться на её идентификатор в заметках и, по возможности, в сообщении коммита.
- `IsaacLab/` — отдельный клон upstream-репозитория со своим `.git` и `AGENTS.md`; `isaac_sc/` содержит локальные материалы сцены. Содержимое обеих папок исключено из корневого Git. При изменении файлов внутри `IsaacLab/` соблюдать его собственные инструкции.

## Общая GPU

- Никогда не останавливать процессы на видеокарте без чёткого разрешения пользователя: GPU общая и может использоваться другими людьми.
- Перед ресурсоёмкими запусками проверять доступность GPU и согласовывать обучение с доступными ресурсами.
